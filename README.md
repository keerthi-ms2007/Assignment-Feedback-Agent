# Assignment Feedback Agent

Internship Project - AI-Powered Assignment Feedback System built with Python & Streamlit.

It auto-grades assignments, provides personalized feedback, detects plagiarism, generates PDF feedback reports, and shows class analytics for teachers and students.

## Features
- Role-Based Login (Teacher / Student)
- Auto-Grading with AI
- Personalized Feedback
- Plagiarism Detection
- PDF Feedback Report Download
- Create Assignment with Rubric
- Class Analytics Dashboard

## Tech Stack
Python, Streamlit, Pandas, Plotly, ReportLab

## How to Run
pip install -r requirements.txt
streamlit run app.py
